Method Unit:ModifyPower [-] [+]

[-] Expand description

modifies the Unit's power amount for the given power type.

enum Powers
{
    POWER_MANA        = 0,
    POWER_RAGE        = 1,
    POWER_FOCUS       = 2,
    POWER_ENERGY      = 3,
    POWER_HAPPINESS   = 4,
    POWER_RUNE        = 5,
    POWER_RUNIC_POWER = 6,
    MAX_POWERS        = 7,
    POWER_ALL         = 127,         // default for class?
    POWER_HEALTH      = 0xFFFFFFFE   // (-2 as signed value)
};

Synopsis 

Unit:ModifyPower( amount, type )

Arguments

number amount

Amount to modify.

Valid numbers: integers from -2,147,483,647 to 2,147,483,647.

number type

Valid numbers: integers from -2,147,483,647 to 2,147,483,647.

Nothing.
